# The First Current — Living Sect (proposal demo)

This Godot 4.7.2 project now holds one demo: **`proposal_demo_living_sect/`**, the version chosen for the thesis proposal.

- **Run:** `proposal_demo_living_sect/Launch Living Sect.cmd`, or open `project.godot` and press F5 (it is the main scene).
- **Guide, controls and review notes:** [proposal_demo_living_sect/README.md](proposal_demo_living_sect/README.md).

The other folders are shared parts the demo loads or was built from: `phase4d/` (the valley), `phase4c/`, `mountain_valley_compact/`, `staging/` (props and walls), `assets/`, `scenes/`, `scripts/`, `baseline/`, `source/` (Blender files), `tools/` (builders) and `addons/`. Don't remove them.

Older demos, reports, checkpoints and launchers were removed on 2026-10-25. They are kept in `../_proposal_archive/2026-10-25-living-sect-cleanup/retired-files.zip`; `KEEP-DELETE.md` there lists what went.

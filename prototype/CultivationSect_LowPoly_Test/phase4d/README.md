Ready for human visual review; Phase 4D is not approved. Phase 4E has not begun.

Double-click **Launch Phase 4D.cmd**, or select
`res://phase4d/phase4d_valley.tscn` in the working Godot project and press F6.

V shows the valley; R returns to the forest start. Existing review shortcuts
and door behavior are inherited unchanged.
